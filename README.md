# Tsukimi — свой аниме-сайт для друзей

Обычный статический сайт: HTML, CSS и JS без сборки. Каталог берётся из AniList, аккаунты и история хранятся в Supabase. Всё это бесплатно.

## 1. Запустить у себя (2 минуты)

Открой папку в терминале и запусти:

    python -m http.server 8000

Затем открой http://localhost:8000. Сайт сразу работает в **локальном режиме**: вход по имени, лайки и история хранятся только в твоём браузере. Этого хватает, чтобы всё посмотреть и проверить.

## 2. Выложить в интернет (бесплатно)

1. Зарегистрируйся на https://pages.cloudflare.com (можно Netlify или Vercel, шаги те же).
2. Создай проект → **Upload assets** → перетащи всю папку с сайтом.
3. Получишь адрес вида `имя.pages.dev`. Его и отправляй друзьям.

Чтобы обновить сайт, загрузи папку заново.

## 3. Включить аккаунты и друзей (Supabase, бесплатно)

1. Зарегистрируйся на https://supabase.com и создай проект.
2. Открой **SQL Editor**, вставь содержимое `supabase/schema.sql`, **сначала заменив `ТВОЙ-КОД-ПРИГЛАШЕНИЯ` на свой код**, и нажми Run.
3. Открой **Project Settings → API**, скопируй `Project URL` и ключ `anon public` в `js/config.js`:

        SUPABASE_URL: "https://xxxx.supabase.co",
        SUPABASE_ANON_KEY: "eyJ...",

4. Если не хочешь подтверждать почту при регистрации: **Authentication → Providers → Email → Confirm email** выключи.
5. Перезалей сайт. Теперь на странице входа есть регистрация. Друзьям отправь ссылку на сайт и код приглашения.

Ключ `anon` можно держать в коде сайта: он публичный по замыслу, доступ ограничивают политики из `schema.sql`.

## 4. Плеер

Видео сайт не хранит. Серии берутся из каталога AniLibria (публичное API, без ключей) и воспроизводятся встроенным плеером на hls.js, без iframe и чужих виджетов. Аниме ищется в AniLibria по названию и сверяется по номеру MyAnimeList, так что похожие названия не путаются.

Что нужно знать:
- В каталоге AniLibria есть не всё. Если аниме там нет (или оно закрыто правообладателем), страница просмотра так и напишет.
- Качество 1080p, 720p или 480p выбирается над плеером и запоминается.
- Адрес API лежит в `js/config.js` (`LIBRIA_API`). Старое API v3 AniLibria закрыто, сейчас используется v1. Если адрес снова сменится, поменяй его там.
- Над плеером есть вкладки: «Источник 1 (AniLibria)», «Источник 2 (Kodik)», «Источник 3 (EN)» и «Трейлер». Если AniLibria тайтл не нашла, сразу открывается резерв, вкладки можно переключать вручную.
- Поиск в AniLibria идёт по очереди: русское название, оно же без подзаголовка и номера сезона, потом английское и ромадзи. Найденный релиз всегда сверяется по номеру MyAnimeList, поэтому другой сезон не подменит нужный.
- Сложные тайтлы можно привязать вручную: `LIBRIA_MAP` в `js/config.js` (номер MyAnimeList: номер или alias релиза в AniLibria).
- «Источник 2 (Kodik)» работает через твой шлюз на Cloudflare Workers (код в `worker/kodik-gate.js`, инструкция ниже). Адрес воркера вписывается в `WORKER_URL` в `js/config.js`; пока он пуст, вкладка отключена. Сайт спрашивает у шлюза ссылку по номеру MyAnimeList и открывает её в рамке.
- «Источник 3 (EN)» (`RESERVE` в `js/config.js`) открывает megaplay.buzz по номеру MyAnimeList: английские субтитры или озвучка, серии кнопками. Рамка идёт без sandbox и с обычным referrer: megaplay иначе отказывает.
- Вкладка «Трейлер» показывает только встроенный YouTube-плеер. Внешних ссылок на сайте нет.
- Часть тайтлов в AniLibria нет вообще (например, «Атака титанов»), там остаётся только резерв.
- Если что-то не открывается, зайди на страницу `#/diag`: она показывает, какие сервисы доступны из твоей сети.
- Сайт запоминает последнюю открытую серию. Минуту, на которой ты остановился, пока не сохраняет.

### Шлюз Kodik на Cloudflare Workers (3 шага)

1. Зайди на https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Create Worker**, назови его, например, `kodik-gate`, нажми **Deploy**, затем **Edit code**.
2. Удали весь код в редакторе, вставь содержимое `worker/kodik-gate.js` и нажми **Deploy**. Потом открой **Settings → Variables and Secrets** и добавь секрет `KODIK_TOKEN` (твой токен Kodik API). По желанию добавь `ALLOW_ORIGIN` и `MIRROR` (описаны в начале файла воркера).
3. Скопируй адрес воркера (вида `https://kodik-gate.имя.workers.dev`), впиши его в `WORKER_URL` в `js/config.js`, закоммить и запушь. Проверка: открой `ТВОЙ_АДРЕС/?id=16498`, должно прийти `{"url":"https://aniqit.com/..."}`.

## Что где лежит

| Файл | Что делает |
|---|---|
| `index.html` | каркас страницы |
| `css/style.css` | весь внешний вид (цвета в начале файла) |
| `js/config.js` | название сайта, ключи Supabase, адрес API видео |
| `js/api.js` | запросы к AniList, Shikimori и AniLibria |
| `js/store.js` | аккаунты, лайки, история, друзья |
| `js/app.js` | страницы, роутинг, рекомендации |
| `supabase/schema.sql` | таблицы и защита для облака |
| `worker/kodik-gate.js` | код шлюза для Cloudflare Workers |

## Как работают рекомендации

Лайк даёт жанрам 3 очка, «просмотрено» 2, «смотрю» 1, «брошено» минус 2. Берутся три главных жанра, ищутся популярные тайтлы в них, добавляется блок «похожее» от AniList для двух последних лайков. Уже добавленное в библиотеку скрывается.
